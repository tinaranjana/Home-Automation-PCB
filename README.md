# ESP32 Home Automation PCB

A custom PCB design for an ESP32-based Home Automation System, designed using KiCad.

## 📌 Project Overview

This project focuses on designing a custom PCB for controlling and monitoring home appliances using an ESP32 microcontroller.

The PCB integrates power supply, relay control, sensor inputs, and switch inputs into a single board.

## 🛠️ Tools & Technologies

- ESP32
- KiCad
- PCB Design
- Schematic Design
- Relay Control
- Sensors
- Switch Inputs
- Power Supply Circuit

## 🔧 Main Sections

The PCB design is divided into the following sections:

- Power Supply Section
- ESP32 Controller Section
- Relay Section
- Sensor Section
- Switch Input Section

## ⚙️ Working

The ESP32 acts as the main controller. Sensor inputs and switch inputs are connected to the controller, while relay outputs can be used to control electrical appliances.

The PCB combines these sections into an organized hardware design suitable for a home automation prototype.
